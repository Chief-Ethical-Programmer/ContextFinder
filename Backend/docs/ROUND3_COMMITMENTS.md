# Round 3 commitments

1. **Continuous knowledge capture and permission-filtered Q&A**: keep approved project context current and answer onboarding questions only from claims cleared for the caller.
2. **Document connectors and stronger matching**: add authorised document-storage connectors and improve cross-source entity matching with measurable conflict and corroboration quality.
3. **Evaluation and operational reliability**: run the planted-case evaluation against real teams, add richer dependency views, retries, monitoring, and deployment observability.

These are product improvements rather than cosmetic UI changes and are intentionally not required for the Round 2 MVP.
